Phone Auto Format

Employees

Work, mobile, private and emergency phones in one format.

Odoo 19Free add-onAuto-installs

This add-on applies your chosen phone format to the contact numbers on employee records.

What you get

Every phone field
Work phone, work mobile, private phone and emergency contact phone are all formatted.
Uses the company’s country
Numbers typed without a country code are read using the employee’s company country – not their nationality, which would give wrong results.
Install and forget
It installs by itself when both Employees and Phone Auto Format are installed.
Requires the free Phone Auto Format module. The format is chosen in Settings → Phone Auto Format.
